# Dinâmicas — Rede Confiança (parceira Vivo)

Quatro experiências gamificadas para eventos presenciais. Cada arquivo funciona
sozinho no navegador: não precisa de instalação, servidor, login nem banco de dados.

| Arquivo | Dinâmica | Celular |
|---|---|---|
| `index.html` | Página inicial com as quatro dinâmicas | — |
| `conexao-adm.html` | Conexão ADM (painel de letras) | sim, por QR Code |
| `missao-confianca-sp.html` | Missão Confiança SP (três missões) | sim, na Missão 01 |
| `debate-relampago.html` | Debate Relâmpago | não |
| `tapa-palavras.html` | Tapa-Palavras | não |

## Publicação

Hospedado em GitHub Pages. O endereço público é necessário para que os
celulares consigam entrar nas dinâmicas multiplayer — quando a página é aberta
pelo link publicado, o QR Code já aponta para o endereço certo automaticamente.

## No dia do evento

1. Abra a dinâmica pelo link publicado (não pelo arquivo salvo no computador).
2. Entre em tela cheia com o botão ⛶.
3. Nas dinâmicas com celular, confira a conexão em ⚙ → Sala → Testar conexão.
